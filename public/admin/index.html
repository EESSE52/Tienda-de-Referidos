Administración D’MonkeySport

Acceso de administración

Introduce el token del servidor local. Solo se mantiene en memoria mientras esta página esté abierta; no se guarda en el navegador. No publiques este panel sin proteger también /admin/ mediante Cloudflare Access.

Categorías de comparación

Puedes crear categorías nuevas y cambiar sus nombres y descripciones. Las métricas y filtros existentes se conservan.

Conecta el administrador para consultar categorías.

Crear categoría

Agregar campo y fórmula de comparación

Agrega una magnitud numérica y el cálculo automático Precio ÷ magnitud. No elimina ninguna fórmula existente.

Configurar campos existentes de una categoría

Para productos como gomitas, crea una categoría copiando Creatina y configura ahí sus campos. Puedes quitar la obligatoriedad de gramos y añadir «Gomitas» como presentación sin cambiar la categoría original.

Conexión OAuth de Mercado Libre (solo pruebas)

Funciona únicamente en el Worker HTTPS de pruebas configurado. Cuando exista un KV exclusivo y los secretos privados, la autorización guarda tokens cifrados. La renovación requiere pulsar el botón: evita ejecuciones simultáneas. No funciona en localhost ni en dmonkeysport.com.

Consultar publicación de Mercado Libre Chile

Pega una URL de publicación MLC o un enlace corto meli.la. Consulta una vista previa, sin guardar ni publicar nada. Un enlace de publicación no necesariamente genera comisiones.

Consultar varios productos de Mercado Libre

Pega hasta 10 enlaces HTTPS de Mercado Libre Chile (también se aceptan enlaces cortos meli.la), uno por línea. El sistema solo consulta y prepara un CSV; no guarda productos ni certifica enlaces de afiliado.

Ingreso manual asistido cuando la API no responde

Si la API responde 403, utiliza «Preparar ingreso manual» junto al enlace rechazado. Identificaremos el ID de vendedor y el catálogo cuando estén presentes en la URL, sin suponer precio ni marca. Después puedes pegar las especificaciones del producto y aplicar los campos reconocidos. El enlace afiliado se introduce y verifica por separado. No se publica nada automáticamente.

Leer fotografía del producto (OCR)

Selecciona una foto clara de la etiqueta o de las especificaciones (JPG, PNG o WEBP, hasta 10 MB). La imagen se procesa en tu navegador; no se envía a la API de D’MonkeySport ni se guarda en D1. Para funcionar, el OCR descarga su motor y diccionarios desde una CDN al pulsar Leer fotografía.

Pegar características copiadas de Mercado Libre

Pega texto «Etiqueta: valor» o tablas Markdown. Se interpretará localmente, sin API. Comprueba la categoría antes de analizar. Ningún dato se guarda automáticamente.

Características para comparar

Revisa los datos antes de agregarlos al CSV. Peso neto, porciones y unidades por envase son medidas diferentes. Los campos con * son obligatorios.

Productos guardados en D1

Los cambios se reflejan en el comparador local después de recargar la página. Desactivar oculta el producto sin eliminar su registro.

Conecta el administrador para ver los resultados.

Monitor automático de precios

Revisión diaria con API autorizada de Mercado Libre. Alerta desde 2 %. No modifica precios ni enlaces: los resultados requieren revisión manual.

Conecta el administrador para consultar las alertas.

Revisión priorizada del catálogo

Diagnóstico de solo lectura de los productos activos: fechas de precios, enlaces afiliados y datos incompletos. No confirma disponibilidad ni actualiza Mercado Libre automáticamente.

Conecta el administrador para revisar el catálogo.

Inteligencia comercial

Conteos diarios agregados, no usuarios únicos. Los clics en enlaces afiliados no significan ventas ni comisiones. No almacenamos datos personales en estas métricas.

Conecta el administrador para ver las estadísticas.

Panel de vendedores y ofertas

Vista de solo lectura basada en las publicaciones guardadas en D1. Agrupa únicamente por Grupo de ofertas explícito o por ID de catálogo; nunca por similitud de nombre. Edita cada publicación por separado. Los precios son referenciales y no incluyen envío.

Conecta el administrador para revisar las ofertas.

Alerta basada en fecha_precio del catálogo. Más de 14 días significa que conviene comprobar el precio, no que el precio haya cambiado. No consulta Mercado Libre ni modifica datos.

Revisión de precios en lote

Selecciona productos MLC no marcados como prueba. Máximo 10 por consulta. Cada precio debe confirmarse individualmente antes de guardarse. La consulta de precio no verifica stock ni afiliación.

Registrar revisión manual de precio

Comprueba el precio en la publicación de Mercado Libre Chile y confirma el importe observado. La revisión se guardará con fecha y fuente, incluso si el precio no cambió. No verifica disponibilidad ni enlace de afiliación.

Historial de precios

Registros guardados en D1. No se consultan precios externos al abrir este historial.

Revisión manual del precio

El precio solo se guardará después de tu confirmación. No cambiará la publicación, el enlace de referido ni el estado del producto.

Crear producto

Para comparar vendedores del mismo artículo, asigna a cada publicación un ID distinto y el mismo Grupo de ofertas. Solo agrupa envases idénticos en marca, peso, sabor y formato. El ID de catálogo también puede vincular publicaciones sin grupo manual.
